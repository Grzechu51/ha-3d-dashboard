# HA 3D Dashboard

HA 3D Dashboard adds a native **3D Home** panel to Home Assistant.

The integration stores projects in Home Assistant, embeds the Pascal 3D editor/viewer,
binds Home Assistant entities to 3D objects, and provides a read-only dashboard mode
for day-to-day control.

## Installation

The supported HACS package is the `ha_3d_dashboard.zip` asset attached to GitHub
releases. After installation, restart Home Assistant and add **HA 3D Dashboard** from
**Settings -> Devices & services**.

This repository is under active development. Project storage uses revision checks to
avoid silently overwriting a newer server copy.
